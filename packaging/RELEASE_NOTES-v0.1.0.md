# MINT Final Channel 0.1.0

Initial public Windows x64 release.

## Highlights

- Persistent English/Chinese Simple and Formal interfaces.
- Clear rounded embedded fonts with no system-font dependency.
- Formal technical parameter names, values, and units remain in English.
- Full controls for 12-band EQ, denoising, compression, reverb and limiter.
- Host metadata standardized as `MINT Final Channel` by `MINT`.

## Validation

- DSP test suite: passed.
- pluginval strictness 10, two randomized repetitions including GUI: passed.
- Steinberg VST3 validator extensive suite: 537 passed, 0 failed.
- Installed-bundle host scan and processing test: passed.

## Windows installation

Extract the ZIP and copy `MINT Final Channel.vst3` to:

`C:\Program Files\Common Files\VST3\`

Restart the DAW and rescan VST3 plug-ins.
